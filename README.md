# India Compliance Assistant

面向中资企业印度业务的中文合规问答应用。它的目标不是“像律师一样猜答案”，而是先从受控资料库找依据，再把结论、法条原文和判例原文一起交给用户核对。

## 这份公开仓库包含什么

- 基于 Next.js / Vinext 的网页与接口代码；
- 资料审核、引用核验、检索、案例归纳、登录、额度和提醒的实现；
- 脱敏后的环境变量示例、迁移脚本、邮件模板和自动化测试。

## 这份公开仓库不包含什么

- `.env.local`、API 密钥、支付/邮件/对象存储凭证；
- 用户账号、密码哈希、会话、附件、对话和运营记录；
- 生产知识库、嵌入向量、案例原文、法律文件和部署包；
- 任何客户资料或服务器配置快照。

法律及案例资料可能受来源网站的使用条款、版权或再利用限制约束。自行部署时，请仅导入你有权使用和再分发的资料，并自行完成来源审核。

## 本地启动

需要 Node.js 22.13+ 与 pnpm 11.24。

```bash
corepack prepare pnpm@11.24.0 --activate
pnpm install --frozen-lockfile
cp .env.example .env.local
pnpm dev
```

`.env.local` 只留在本机或服务器，永远不要提交。按照 `.env.example` 填入所需的模型、邮件、支付和数据库配置；缺少配置的外部功能会安全停用。

## 验证

```bash
pnpm lint
pnpm test
pnpm build
```

测试使用隔离的临时目录和固定验证码，不会发送真实邮件，也不会访问生产数据。

## 安全原则

- 结论必须回溯到资料库中的法条、官方资料或判例；资料不足时拒绝编造；
- 用户密码仅保存 scrypt 哈希，会话只保存令牌哈希；
- 注册和重置密码使用一次性、十分钟有效的邮箱验证码；
- 重置密码会撤销该账号在其他设备上的旧会话；
- 本地运行数据默认存于 `.local-data/`，并被 Git 忽略。
